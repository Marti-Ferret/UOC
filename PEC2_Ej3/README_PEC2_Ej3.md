## Ordres per executar i transpilar i l'aplicació:

# 1. Llençar la comanda "npm install" per instalar les dependencies del projecte.
# 2. Llençar la comanda "npm run build" per transpilar els fitxers TypeScript i generar el fitxer dist/bundle.js mitjançant Webpack.
# 3. Obrir el fitxer index.html al navegador per executar l'aplicació.

## Fitxers Webpack d'exemple proporcionats:

# Sobre els dos fitxers d'exemple:
# 1. webpack.config.eje3-base.example: configuració base amb ts-loader. S'ha adaptat canviant l'entry de ./src/app.ts a ./app.ts i afegint mode: 'development' per evitar un warning en el build.
# 2. webpack.config.eje3.example.js: no s'ha utilitzat ja que conté paquets incessaris.
